# Skill：案例库驱动的拼接式方案讨论（衡复 / 可玩城市）

供 Agent 踏勘「深化讨论」环节使用。与《徐家汇数据分析完整手册》第四章 **物理层融合维度** 对齐。

## 四维案例标签（每条案例至少标一个主维度）

| 维度 key | 含义 | 讨论时要回答的问题 |
|----------|------|-------------------|
| `concept` | 概念维度 | 抽什么理念（边界模糊、时间层叠、偶发相遇…）？ |
| `site_treatment` | 场地处理 | 地面、边界、竖向、轴线与视廊怎么动？ |
| `material_sensory` | 材料与感官 | 触感、光影、声景、植物层次如何拼？ |
| `program` | 程序与使用模式 | 自发占用、策划活动、偶遇结构如何移植？ |

## 工作方式（强制）

1. **先读结构化案例包**：每条含 `id`、`title`、`summary`、主/次维度、适用条件。
2. **按需引用**：讨论中显式写「引用案例 id：xxx」说明为何与本地场地匹配。
3. **拼接而非单抄**：最终方案必须 **从四个维度各至少选 1 条** 不同案例，说明 **组合逻辑**（谁解决什么问题、时序上谁先谁后）。
4. **转译**：输出用「本地语句」描述策略，避免照搬案例标题当方案名。

## 输出结构建议（主持人）

- 共识 / 分歧  
- **拼接方案**：分四段对应四维，每段写清「引用 id + 本地转译 + 与指标(E/S/AC/N_CD/N_OS/N09)的对应关系」  
- 现场核验清单  

## 数据文件

静态案例库：`data/agent-case-library.json`（可替换为真实项目库，保持字段一致即可）。
